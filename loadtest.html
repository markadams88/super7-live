How many students can actually connect at once.

What this does

It opens real database connections, one per pretend student, writes a name and an answer for each, then closes them all. Firebase allows 100 at once on the free plan and 200,000 on Blaze, so this is the quickest way to prove which plan you are actually on. It writes to a throwaway session and never touches a live one.
